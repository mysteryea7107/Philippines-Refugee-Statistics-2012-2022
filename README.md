Philippines Refugee Statistics Analysis (2012–2022)

Author: ANTIC, Emerson C.

Report Date: October 11, 2026

📋 Overview

This repository contains the applied data mining report, exploratory analysis, and visualization resources examining refugee and asylum-seeker statistics associated with the Philippines from 2012 to 2022. The dataset encompasses 722 total recorded individuals (512 refugees and 210 asylum-seekers) originating from 31 distinct countries.

🗂️ Repository Structure

Dataset/ — Contains raw/sample data files and variable descriptions (dataset.txt).

Data Visualization/ — Visual assets, charts, and summary graphics (Scorecards, Pie Charts, and Combo Charts).

Presentation/ — Slides and presentation material corresponding to the visualization task.

📊 Dataset & Variables

The dataset comprises 7 primary attributes categorized into qualitative and quantitative types:

| Variable | Classification | Subtype | Description |
| Year | Qualitative | Ordinal / Temporal | Year recorded ($2012$ to $2022$) |
| Asylum Country | Qualitative | Nominal | Country/category recorded in asylum field |
| Country-of-origin | Qualitative | Nominal | Country of origin of the individual |
| Country-of-asylum | Qualitative | Nominal | Country where asylum was sought/received |
| UNHCR-refugees | Quantitative | Discrete | Number of recorded refugees |
| Asylum-seekers | Quantitative | Discrete | Number of recorded asylum-seekers |
| Total-count | Quantitative | Discrete | Total recorded individuals in observation |

📈 Data Visualization

The project highlights key findings through three core visualization types:

Scorecards: High-level summary metrics displaying total refugees ($512$), total asylum-seekers ($210$), combined population ($722$), and represented countries ($31$).

Pie Chart: Proportional breakdown by country of origin, highlighting leading contributors such as Pakistan ($15.0\%$), Syrian Arab Republic ($14.5\%$), and Iran ($12.9\%$).

Combo Chart: Dual-axis visualization comparing yearly trends from $2012$ to $2022$ using column bars for asylum-seekers alongside a progression trend line.
